# HKU-POLI3148-Dashboard

**Live Dashboard:** [https://kenny-choww.github.io/HKU-POLI3148-Dashboard/](https://kenny-choww.github.io/HKU-POLI3148-Dashboard/)

**Coursework:** The University of Hong Kong (HKU) - POLI3148 Data Science in Politics and Public Administration

## Project Details

This project is a web-based dashboard showcasing the **Varieties of Democracy (V-Dem)** dataset, allowing users to interactively analyze and visualize metrics related to democratic quality and regime changes globally and regionally over time. 

The dashboard provides visual insights into global trends, empowering researchers, students, and analysts to understand how different countries transition into or out of democratic governance structures based on the comprehensive metric data gathered by the V-Dem Institute.

### Files Included
- `index.html`: The core interactive HTML dashboard.
- `Dashboard_builder.py`: The Python script responsible for building or generating the dashboard contents based on the given dataset.
- `V-Dem-CY-Full+Others-v15.csv` (compressed): The comprehensive database of global governance regimes and indicators used for dashboard reporting.

## Deployment
This repository is deployed automatically using GitHub Pages directly from the `main` branch. The data has been compressed to satisfy large file restrictions on GitHub repositories.
